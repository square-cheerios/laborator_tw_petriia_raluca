# City Explorer

City Explorer este o machetă statică pentru un mini-ghid de călătorie,
realizată folosind HTML și CSS în cadrul disciplinei Tehnologii Web.

Pagina prezintă mai multe destinații și permite utilizatorului să
completeze un formular simplu pentru planificarea unei excursii.

Pentru redactarea și organizarea unei părți din conținutul proiectului a fost utilizat ChatGPT ca instrument de asistență.
