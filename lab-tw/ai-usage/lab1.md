# AI Usage Log - Laboratorul 1

## Instrument utilizat
ChatGPT (OpenAI)

## Mod de utilizare
ChatGPT a fost folosit ca instrument de asistență pentru realizarea laboratorului.

A fost utilizat pentru:
- explicarea pașilor necesari pentru conectarea folderului local la repository-ul GitHub;
- clarificarea comenzilor Git precum `git init`, `git add`, `git commit`, `git remote add origin` și `git push`;
- organizarea structurii HTML pentru proiectul City Explorer;
- redactarea și ajustarea fișierului CSS;
- explicarea utilizării elementelor semantice HTML;
- explicarea Flexbox și CSS Grid;
- ajustarea paletei de culori și a aspectului vizual al paginii;
- redactarea unei mențiuni privind utilizarea ChatGPT în documentația proiectului.
